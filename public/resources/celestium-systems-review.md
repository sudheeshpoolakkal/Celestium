## Maintainability perspective

- Which components need access for inspection or replacement?
- What adjacent systems must be disturbed to reach them?
- How will configuration and component revision be recorded?
- What tools, skills and supporting infrastructure does the installation imply?
- Which high-energy interfaces need an isolation concept to be researched?

## Validation perspective

- What does each model explain, and what does it leave unresolved?
- Which assumptions have the largest effect on the outcome?
- Which fault cases or environmental limits require further analysis?
- What evidence would support the next design decision?
- Where does a proposed requirement lack a clear source?
